# MonitorShop

MonitorShop is an e-commerce project that I developed using ASP.NET Core MVC.


### Features

* product listing and management
* category management
* adding, updating and deleting data
* database operations with Entity Framework Core
* layered architecture
* separation of business and data access operations

### Technologies

* C#
* ASP.NET Core MVC
* Entity Framework Core
* SQL
* HTML
* CSS
* Bootstrap

### Project Structure

The project is separated into different layers to keep the code more organized and easier to manage.

**Entities**
contains the models used in the project

**DataAccess**
handles database operations

**Business**
contains the business logic and related operations

**Web**
contains the MVC side of the project such as controllers and views

### What I Learned

While developing MonitorShop, I improved my understanding of ASP.NET Core MVC and layered architecture.

I also gained more experience with Entity Framework Core, database operations and separating different responsibilities in a project.
